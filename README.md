# نظام مسار لإدارة الشركة

واجهة ويب احترافية لتجربة لوحة تحكم وإدارة أعمال الشركات، مع شاشة رئيسية، شات بوت داخلية، وإدارة العملاء والطلبات والمخزون.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح:

http://localhost:3000

## المميزات

- تصميم عربي حديث ومتجاوب
- واجهة رئيسية احترافية للعرض
- شاشة تسجيل دخول مع 2FA موضحة تجريبياً
- لوحة تحكم إدارية
- CRM لإدارة العملاء والطلبات
- إدارة المخزون والفواتير
- شات بوت داخل النظام
- تصميم متقدم ويوفر تجربة جذابة

## ملاحظات

هذا مشروع واجهة أمامية احترافية (Frontend prototype) يساعد في عرض النظام، وهو مناسب لتطويره لاحقاً إلى تطبيق كامل مع Backend وDatabase.
